# AI-native practice profile

Use this profile for first-hand writing about building and operating AI-native systems. The item belongs here when its main value is a reusable practice in one of these three areas:

- AI-native product design: the product is redesigned around a model capability. A chat box added to an existing screen is not enough.
- Team workflows and human-AI collaboration: how engineering, research, or operations divides work with models, and which quality controls sit on that division.
- Implementation cases: a concrete method that was tried, with results and failure lessons. Open-source examples and first-hand postmortems belong here.

Do not use this profile for release announcements, funding or product marketing, concept essays without a method, benchmark leaderboard posts, or beginner API and RAG tutorials. When the piece mainly reports that something shipped or happened, use a news profile even if the subject is AI.
